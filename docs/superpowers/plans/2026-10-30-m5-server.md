# M5：Spring Boot 服务壳（REST 配置管理 + 聊天接口）实现计划

> **For agentic workers:** 使用 superpowers:executing-plans（inline）。步骤用 `- [ ]` 跟踪。

**Goal:** 交付可运行的 Spring Boot 服务壳：配置管理 REST（agents/skills）+ 聊天接口，把 core/core-llm/tools-http/config-jdbc 装配起来。

**Architecture:** 新建 `server` 模块；`ChatModelFactory`（函数式）+ `AgentRuntime`（按配置构建 AgentLoop 并聊天，纯逻辑可单测）+ `AgentController`（REST）。默认用 `InMemoryConfigRepository`，MySQL 通过注入 `JdbcConfigRepository` 切换。SSE 流式延后（非流式 `/chat` 先可用）。

**Tech Stack:** Spring Boot 3.3.5（starter-web + starter-test）、Java 17；依赖 core/core-llm/tools-http/config-jdbc。

**Spec:** `docs/superpowers/specs/2026-10-30-agentloom-design.md`（§5、§8、§11 M5）

## Global Constraints

核心库仍零 Spring；Spring 只出现在 `server`。`mvn` 同前。

## Review Focus

| # | 输入/失效情形 | 合理期望 | 测试 |
|---|---|---|---|
| 1 | 聊天的 agentId 不存在 | 抛明确异常（404） | Task 2 |
| 2 | skill 引用了未注册的 toolName | 忽略该 tool，不崩 | Task 2 |
| 3 | 保存空 id 的 agent | 400 / 拒绝 | Task 2（复用 repo 校验） |

### Task 1: server 模块 + ChatModelFactory

**Files:** Create `server/pom.xml`（spring-boot-starter-web、spring-boot-starter-test、依赖 core/core-llm/tools-http/config-jdbc）；父 pom `<modules>` 加 `server`；Create `server/src/main/java/com/aia/server/AiAgentApplication.java`（@SpringBootApplication）、`ChatModelFactory.java`

**Produces:**
```java
@FunctionalInterface
public interface ChatModelFactory { ChatModel create(String modelName); }
```

先写 `ChatModelFactoryTest`（lambda 调用）确认工厂契约，再写实现。`AiAgentApplication` 能 `mvn spring-boot:run` 启动（本任务只验证 `mvn -q compile` 过）。

### Task 2: AgentRuntime + 单测

**Files:** Create `server/src/main/java/com/aia/server/AgentRuntime.java`；Test `server/src/test/java/com/aia/server/AgentRuntimeTest.java`

**Produces:**
```java
public final class AgentRuntime {
    public AgentRuntime(ConfigRepository repo, ToolRegistry tools, ChatModelFactory factory);
    public String chat(String agentId, String userMessage);   // agent 不存在抛 IllegalArgumentException
    public List<AgentConfig> listAgents();
    public List<SkillConfig> listSkills();
    public void saveAgent(AgentConfig c); public void deleteAgent(String id);
    public void saveSkill(SkillConfig c); public void deleteSkill(String name);
}
```

`chat` 内部：按 `AgentConfig` 用 `factory.create(model)` 建模型，`skillNames` 解析成 `Skill`（`toolNames` 从 `ToolRegistry` 查、查不到忽略），`new AgentLoop(...).run(userMessage)`。

测试（fake `ChatModelFactory` 返回脚本化 ChatModel + `InMemoryConfigRepository` + `ToolRegistry`）：`chatReturnsAnswer`、`chatUnknownAgentThrows`、`skillToolIgnoredWhenNotRegistered`。

### Task 3: AgentController + Spring Boot 冒烟测试

**Files:** Create `server/src/main/java/com/aia/server/AgentController.java`、`AgentConfiguration.java`（`ChatModelFactory` 与 `ConfigRepository` 默认 bean）；Test `server/src/test/java/com/aia/server/AgentControllerTest.java`

**Produces:**
```java
@RestController @RequestMapping("/api")
public class AgentController {
    GET/POST/DELETE /api/agents；GET/POST/DELETE /api/skills；
    POST /api/chat/{agentId}（body {"message":"..."} → {"answer":"..."}）
}
```

`AgentConfiguration`：`ChatModelFactory` 默认 bean（用 `OpenAiCompatibleChatModel` + 配置 baseUrl/apiKey，来自 `@Value`，默认空）、`ConfigRepository` 默认 `InMemoryConfigRepository`。

测试（`@SpringBootTest` + `MockMvc` + `@TestConfiguration` 注入 fake `ChatModelFactory`）：`listAgentsReturns200`、`saveAndListAgentRoundTrip`、`chatReturnsAnswer`。
