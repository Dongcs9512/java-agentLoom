# M3：RAG 管道 + VectorStore SPI + 内存实现 实现计划

> **For agentic workers:** 使用 superpowers:executing-plans（inline）。步骤用 `- [ ]` 跟踪。

**Goal:** 交付 RAG 知识库能力：文本分片、向量化、向量存储 SPI、相似度检索、按 chunkId 增量更新。先落地内存实现（无需外部服务即可用），SPI 就绪后 ES/Redis 适配器可插拔接入。

**Architecture:** 新建 `core-rag` 模块；`EmbeddingModel` SPI + `VectorStore` SPI + 数据模型 + `TextChunker` 分片 + `InMemoryVectorStore`（余弦相似度暴力检索）+ `KnowledgeBase` 门面。核心零 Spring。

**Tech Stack:** 同前（Java 17、Jackson、JUnit 5）；本里程碑**不引入** ES/Redis 客户端依赖。

**Spec:** `docs/superpowers/specs/2026-10-30-agentloom-design.md`（§5、§6.8、§6.9、§11 M3）

### Task 1: 数据模型 + SPI

**Files:** Create `core-rag/pom.xml`（依赖 jackson、junit；父 pom `<modules>` 加 `core-rag`）；Create `core-rag/src/main/java/com/aia/rag/VectorRecord.java`、`SearchHit.java`、`VectorQuery.java`、`VectorStoreCapability.java`、`EmbeddingModel.java`、`VectorStore.java`；Test `core-rag/src/test/java/com/aia/rag/ModelTest.java`

**Produces:**
```java
public record VectorRecord(String id, String text, float[] vector, Map<String,Object> metadata) {}
public record SearchHit(String id, String text, float score, Map<String,Object> metadata) {}
public record VectorQuery(float[] vector, int topK, Map<String,Object> filter) {}
public enum VectorStoreCapability { METADATA_FILTER, BATCH_UPSERT }
public interface EmbeddingModel { float[] embed(String text); int dimension(); }
public interface VectorStore {
    void upsert(List<VectorRecord> records);
    List<SearchHit> search(VectorQuery query);
    void delete(List<String> ids);
    void update(List<VectorRecord> records);   // 按 id 替换
    Set<VectorStoreCapability> capabilities();
}
```

测试（纯构造/不可变）：records 的 `id/text/vector` 存取正确、`SearchHit` 字段正确。

### Task 2: TextChunker 分片

**Files:** Create `core-rag/src/main/java/com/aia/rag/TextChunker.java`；Test `core-rag/src/test/java/com/aia/rag/TextChunkerTest.java`

**Produces:**
```java
public final class TextChunker {
    public List<String> chunk(String text, int maxChars, int overlapChars);
}
```

固定字符窗口分片：`maxChars` 为块最大字符数，`overlapChars` 为相邻块重叠字符数；空/blank 文本返回空列表。

测试：`emptyTextReturnsEmptyList`、`shortTextReturnsSingleChunk`、`chunksWithOverlap`（断言块数与首块/重叠内容）。

### Task 4: KnowledgeBase 门面（RAG 管道）

**Files:** Create `core-rag/src/main/java/com/aia/rag/KnowledgeBase.java`；Test `core-rag/src/test/java/com/aia/rag/KnowledgeBaseTest.java`

**Produces:**
```java
public final class KnowledgeBase {
    public KnowledgeBase(EmbeddingModel embedder, VectorStore store, TextChunker chunker,
                         int chunkSize, int overlap);
    public void addDocument(String docId, String text);   // 分片 → embed → upsert，chunkId = docId + "#" + i
    public List<SearchHit> search(String query, int topK); // embed(query) → store.search
    public void updateChunk(String chunkId, String newText); // 重新 embed + store.update
    public void deleteDocument(String docId);              // 删所有该 docId 前缀的 chunk
}
```

测试（用一个固定向量 fake `EmbeddingModel`）：`addAndSearchReturnsRelevantChunk`、`searchEmptyQueryReturnsEmpty`、`updateChunkChangesContent`、`updateMissingChunkIsNoop`、`deleteDocumentRemovesAllChunks`。
